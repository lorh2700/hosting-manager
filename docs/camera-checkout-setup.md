# 복도 카메라로 체크아웃 확인하기 — 설정 안내 (별하재 Reolink)

카메라가 사람을 감지하면 사진을 메일로 보내고, 호스팅 매니저가 5분마다 그 메일함을 읽어 사진을 저장하고
체크아웃 시간대(09:00~13:30 KST)에는 AI 가 "짐을 들고 나가는 게스트인지" 판정합니다.
퇴실로 보이면 호스트에게 문자가 가고, 오늘 화면의 체크아웃 카드에 사진과 판정이 뜹니다.
확정은 호스트가 카드의 **체크아웃 확인** 버튼을 눌러서 합니다. 그러면 청소담당자에게 알림이 갑니다.

Reolink Cloud 에 저장된 영상은 공식 API 가 없어 프로그램이 읽을 수 없습니다. 그래서 카메라 자체의
이메일 전송 기능을 씁니다 (클라우드 구독과 무관하게 카메라 기본 기능).

## 1. 카메라 전용 Gmail 계정 (호스트가 한 번)

1. 새 Gmail 계정을 만듭니다. 예: `voidanchae.cam@gmail.com`
2. Google 계정 → 보안 → **2단계 인증** 켜기
3. Google 계정 → 보안 → **앱 비밀번호** 에서 두 개 만들기 (16자, 공백은 빼고 씁니다)
   - 이름 `Reolink` → 카메라에 넣을 비밀번호
   - 이름 `hosting-manager` → Netlify 환경변수에 넣을 비밀번호
4. 이 계정의 비밀번호를 바꾸면 앱 비밀번호가 모두 취소되니 바꾸지 마세요.

## 2. 카메라 설정 (Reolink 앱 → 카메라 → 설정)

1. **이메일 알림(Email Alert)** 켜기
   - SMTP 서버 `smtp.gmail.com`, 포트 `465`, SSL/TLS 켬
   - 보내는 사람 = 위 Gmail 주소, 비밀번호 = 앱 비밀번호 `Reolink`
   - **받는 사람** = `voidanchae.cam+byulha@gmail.com` 처럼 주소에 `+숙소slug` 를 붙입니다. 이 태그로 지점을 구분합니다.
     - 별하재 `+byulha`, 안온재 `+anon`, 운와당 `+unwadang`, 화연재 `+hwayeonjae`
   - 이메일 내용 = **Text with Picture** (사진 1장 첨부)
   - 알림 종류 = **사람(Person)** 만
   - 간격(Interval) = 1분
   - 스케줄 = 매일 08:00~14:00 (체크아웃 시간대만 보내 메일 수를 줄입니다)
2. 카메라 이름은 호스팅 매니저 숙소 설정의 **복도 카메라 이름** 과 같게 두면 +태그 없이도 지점을 찾습니다.
3. 테스트: 복도를 한 번 지나가 보고 Gmail 받은편지함에 사진 메일이 오는지 확인합니다.

## 3. 호스팅 매니저 쪽 (개발자/관리자가 한 번)

1. Supabase → SQL Editor 에서 `prisma/migrations/20260906150000_camera_snapshots/migration.sql` 실행
2. Supabase → Storage 에서 **비공개** 버킷 `camera-snapshots` 생성 (Public 끄기)
3. Netlify → 환경변수
   - `CAMERA_IMAP_USER` = Gmail 주소
   - `CAMERA_IMAP_PASSWORD` = 앱 비밀번호 `hosting-manager` (공백 제거)
   - `SUPABASE_STORAGE_BUCKET_CAMERA` = `camera-snapshots`
   - `ANTHROPIC_API_KEY` = Claude API 키 (없으면 사진만 저장하고 판정은 건너뜁니다)
   - `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` 가 이미 있는지 확인
4. 배포하면 예약 함수 `camera-inbox-cron` 이 5분마다 돕니다. 관리자 로그인 상태에서 `POST /api/cron/camera-inbox` 를 호출하면 바로 한 번 돌고 결과 요약이 옵니다.
5. 숙소 설정 → **복도 카메라 이름**, **카메라 위치 설명** 을 채웁니다. 위치 설명은 AI 에게 어느 쪽이 현관인지
   알려주는 문장입니다 (예: "화면 왼쪽이 현관, 오른쪽이 객실. 청소팀은 파란 앞치마").

## 4. 동작 규칙

- 판정 조건: 사람이 있고, 캐리어·큰 가방을 들었고, 객실 쪽이 아닌 방향이고, 직원 단서가 없고, 확신도 0.7 이상
- 하루에 처음 퇴실로 판정된 순간에만 호스트에게 문자 1건. 그 뒤 사진은 카드에만 쌓입니다.
- 사진은 30일 뒤 자동 삭제됩니다 (개인정보 보호법 표준지침의 30일 기준).
- 비용: 사진 1장 판정에 약 1~3원 수준(720p 기준). 하루 몇 장이면 월 수백 원.

## 5. 개인정보 안내 (해야 할 것)

- 복도 CCTV 안내판에 "체크아웃 확인·청소 준비" 목적을 추가하고, 보관 기간 30일과 책임자 연락처를 적습니다.
- 개인정보 처리방침에 "복도 영상 스냅샷을 체크아웃 확인 목적으로 국외 AI 서비스(Anthropic, 미국)에 처리 위탁"을 명시합니다.
- 카메라는 복도만 비추고 객실 내부·화장실은 비추지 않습니다.

## 6. 자주 겪는 문제

- 메일은 오는데 카드에 안 뜸 → 받는 주소의 +태그가 숙소 slug 와 다르거나, 숙소 설정의 카메라 이름이 비어 있음
- 판정이 안 됨 → `ANTHROPIC_API_KEY` 미설정, 또는 감지 시각이 09:00~13:30 밖, 또는 그날 그 숙소에 체크아웃이 없음
- 밤 사진(흑백)은 판정 확신도가 낮게 나오는 게 정상입니다
