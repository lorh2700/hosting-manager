# 매니저 업무 웹앱

기존 계정과 va_session 인증을 공유합니다. 청소 계정은 /cleaner로 이동하며, 관리자·매니저는 관리자 메뉴의 ‘매니저 업무 화면’으로 들어갑니다. 하단 메뉴는 오늘·일정·세탁·비품·신고입니다. 기존 청소 신청·기록·설정은 상단 더보기에 있습니다.

## 세탁

/cleaner/laundry 와 /admin/laundry 는 같은 컴포넌트/API/DB를 사용합니다. 수거 건은 숙소별로 구분합니다. 수거 예정 → 수거 완료 → 세탁 중/배송 중 → 부분 입고/입고 완료 순서입니다. 이번 입고 수량을 누적하고 미입고를 자동 계산합니다. 파손·재세탁은 입고 수량의 부분집합입니다. 별도의 재세탁 출고가 필요하면 새 수거 건을 등록합니다.

일정·배송 수정으로 예정일, 업체 연락처, 전달 메모를 바꿀 수 있습니다. 수량 정정에는 사유가 필요하며 완료 건의 입고 수량을 줄이면 부분 입고로 다시 열립니다. 모든 수정은 서버 계정 정보·전후 수량·시각을 남깁니다. version 비교로 동시 수정 및 같은 입고 요청의 중복 반영을 차단합니다. 새 건의 UUID는 클라이언트가 생성하여 네트워크 재시도에도 재사용합니다. 최근 300건을 표시합니다.

권한은 기존 visibleScope를 따릅니다. 청소 계정의 경우 CleanerProperty 배정이 있으면 그 숙소만, 배정이 없으면 기존 규칙대로 소유 호스트의 숙소를 표시합니다. 담당 지점 제한이 필요하면 관리자에서 명시적으로 배정해야 합니다.

## 설치와 오프라인

기존 사이트 매니페스트를 재사용합니다. 매니저 화면의 설치 안내에서 홈 화면 추가 방법을 볼 수 있습니다. manager-sw.js는 청소 화면 탐색 실패 시 연결 안내만 표시합니다. 게스트 정보·업무 목록·API 응답은 캐시하지 않으며 오프라인 작업 저장을 지원하지 않습니다.
