# void anchae 모바일 운영 UX 점검

점검일: 2026-09-09

범위: 현재 저장소의 관리자/청소담당자 화면, 로그인, 하단 메뉴, 정비, 공통 UI를 코드 기반으로 점검했다. 실제 로그인한 운영 화면, 기기별 터치·키보드·뒤로가기·화면 대비는 실기기 검증 전이다. 아래에서 코드로 확인한 동작과 개선 제안을 구분한다. 제품 코드는 변경하지 않았다.

## 판단

앱 설치 형태와 하단 메뉴는 갖춰졌지만, 업무를 시작하고 끝내는 흐름은 여러 관리 페이지에 분산되어 있다. 매번 사용자가 읽고 해석해서 다음 화면을 선택해야 한다. 디자인 변경보다 먼저 '오늘 어떤 숙소에 무엇을 해야 하는지'와 '처리 결과가 무엇인지'를 명확히 해야 한다.

## 제안하는 화면 구성

관리자 하단 메뉴: **오늘 / 예약 / 메시지 / 더보기**.

- 오늘: 오늘 작업이 있는 숙소, 확인할 사항, 숙소별 작업 상세. 기존 정비 기능을 이곳에서 바로 처리한다.
- 예약: 미래 일정 탐색, 달력/목록 전환, 직접 예약 등록·취소. '예약'과 '캘린더'를 별도 목적처럼 나누지 않는다.
- 메시지: 전체 대화와 미응답 확인. 정비 중에는 같은 숙소 상세에서 대화를 볼 수 있게 한다.
- 더보기: 숙소 설정, 유지보수 차단 등록, 담당자/사용자, 보고서, 투어 전환, 프로필.
- 알림함: 오늘 화면 상단의 종 아이콘으로 접근한다. 빈도가 아직 확인되지 않은 별도 하단 탭은 추가하지 않는다.

청소담당자 하단 메뉴: **오늘 / 일정 / 신청 / 더보기**. 오늘은 본인에게 배정된 작업을 우선하고, 다른 담당자의 상태는 보조 정보로 둔다.

기존 `/admin/ops` 링크와 알림 링크는 계속 유효하게 유지하되 같은 작업 화면으로 연결한다.

## 오늘의 숙소 카드

목록에서 항상 보일 정보:

1. 숙소명과 지금 확인할 사항: 예) 별하재 · 체크아웃 확인 필요
2. 오늘 입실 게스트, 투숙 시작/종료일·박 수, 예정 입실 시각
3. 오늘 퇴실 게스트, 예정 퇴실 시각, 실제 확인 상태
4. 청소담당자와 청소 상태
5. 얼리/레이트/특별 요청 요약 및 관련 대화로 가는 버튼
6. 현재 상태에 맞는 대표 행동 하나

긴 대화 전체를 목록에 펼쳐 두지 않는다. 관련 대화를 접어 숨길 때도 요청 존재 여부와 읽지 않은 메시지 수는 남긴다. 중요한 요청은 최신 메시지 몇 개 밖으로 밀려나도 남아 있어야 한다.

얼리/레이트 태그는 현재 키워드 탐지 결과이므로 합의된 시간으로 표시하면 안 된다. `문의 있음`, `확정 12:00`, `거절/해결됨`을 구분하고 확정은 담당자가 기록하게 한다. 예약별 메모와 출처 대화를 연결한다.

## 상태와 행동

한 개의 '완료' 배지로 모든 작업을 표현하지 않는다.

| 상태 축 | 예시 | 가능한 대표 행동 |
| --- | --- | --- |
| 퇴실 | 미확인 / 카메라 후보 / 패드 신고 / 매니저 확인 | 사진·대화 확인 → 퇴실 확인 |
| 청소 | 미배정 / 배정됨 / 완료 | 담당자 배정 또는 청소 완료 기록 |
| 입실 안내 | 미전송 / 전송 중 / 전송됨 / 실패 | 안내 보내기 또는 메시지만 재시도 |

카메라 후보는 실제 체크아웃 확정과 구별한다. 미확인이라고 해서 현실의 예외 처리를 막는 것은 피하고, 필요한 경우 매니저가 근거를 확인해 처리한다. 완료사진은 추가하지 않는다.

## 편안함을 위한 표현 규칙

- 갈색 브랜드 색상은 유지한다. 배경 장식보다 숙소명·시간·다음 행동의 위계를 먼저 정리한다.
- 날짜·상태마다 색을 달리하지 않는다. 기본은 중립색, 주의는 주황, 실패는 빨강, 완료는 녹색으로 제한한다.
- '정비 완료'는 일반 청소와 유지보수 완료로 읽힐 수 있다. 일상 작업은 '청소 완료', 객실 차단은 '유지보수'로 구분한다.
- 중요한 실패는 카드에 남기고 재시도를 제공한다. 마지막 확인 시각과 갱신 실패를 표시하여 오래된 정보를 현재 상태로 오해하지 않게 한다.
- 화면 이동 뒤 필터·스크롤·선택 숙소를 복원한다. 알림을 누르면 해당 작업으로 바로 들어간다.

## 구현 순서

1. 로딩/실패 표시, 청소 완료와 메시지 전달 상태, 로그인 통일을 먼저 정리한다.
2. 오늘·정비를 하나의 운영 흐름으로 통합하고 숙소 요약 카드와 작업 상세를 만든다.
3. 청소담당자 오늘/일정과 공통 터치·시트·뒤로가기를 정리한다.
4. 알림함과 오늘 청소 푸시를 연결한다. 기존 알림톡과 사용자 설정은 유지한다.

## 실기기 검증 기준

- 390px 폭에서 첫 화면만 보고 오늘 작업 지점과 가장 먼저 할 일을 설명할 수 있는가?
- 해당 숙소의 체크인 이름·투숙일, 레이트 체크아웃 합의, 관련 대화까지 헤매지 않고 접근하는가?
- 실패한 조회가 무한 로딩이나 일정 없음처럼 보이지 않는가?
- 메시지 전송만 실패했을 때 청소 완료를 다시 누르지 않고 복구할 수 있는가?
- 한 손으로 버튼을 누르기 쉽고 키보드가 제출 버튼을 가리지 않는가?
- 상세를 닫거나 뒤로 가면 같은 숙소·스크롤 위치로 돌아오는가?
- 로그인 만료/앱 재실행/알림 진입 후에도 원래 작업을 이어갈 수 있는가?

위 항목은 목표이며 아직 사용자 테스트로 검증된 성과가 아니다.
