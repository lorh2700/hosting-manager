# 숙소 고정 체크아웃 QR

관리자 → 숙소 → 해당 숙소 → **체크아웃 QR**에서 QR PNG를 저장해 객실 안내문에 붙입니다. 같은 숙소에는 같은 QR이 발급되므로 매 예약마다 교체할 필요가 없습니다. 게스트에게 링크를 직접 안내할 수도 있습니다.

게스트는 QR을 스캔하고 숙소명·오늘 날짜를 확인한 뒤 퇴실 확인란과 **체크아웃 완료**를 누릅니다. 스캔/조회 자체는 아무 상태도 변경하지 않습니다. 관리자 오늘 화면에 게스트 셀프 체크아웃이 기록되고 기존 알림 설정에 따라 호스트와 청소 담당자에게 알림을 시도합니다. 카메라 판정과 별도로 동작합니다.

현재 숙소 단위 체크아웃 구조에 맞춰 해당 숙소에 오늘 퇴실하는 예약 이벤트가 정확히 하나 있을 때만 완료를 허용합니다. 예약 동기화가 안 됐거나 여러 퇴실 예약이 있으면 호스트에게 문의하도록 안내합니다. QR을 통한 체크아웃은 운영상의 퇴실 확인이며 Beds24 예약 취소나 결제/환불을 실행하지 않습니다.

QR에는 숙소에 한정된 서명 링크가 들어갑니다. 서명은 기존 `JWT_SECRET`으로 생성하며 패드 API 키나 로그인 권한은 포함하지 않습니다. 링크를 가진 사람은 오늘의 체크아웃 확인 화면에 접근할 수 있으므로 숙소 안내용으로 배포합니다. `JWT_SECRET`을 교체하면 기존 QR도 무효가 되므로 재출력이 필요합니다. 개별 QR 폐기·재발급 기능은 포함하지 않습니다.

운영 URL은 `CHECKOUT_SITE_URL`, Netlify `URL`, 요청 도메인 순서로 결정합니다. 운영 사이트에서 QR을 내려받아 실제 휴대폰으로 링크가 열리는지 확인한 뒤 부착하세요. 서버에서 QR을 생성하며 외부 QR 생성 서비스에 링크를 전달하지 않습니다. 별도의 환경변수나 DB 마이그레이션은 필요하지 않습니다.

확인 실패와 문자 전송 실패는 다릅니다. 체크아웃 기록 후 문자 전송에 실패해도 게스트 화면은 기록 완료를 표시하며, 관리자 오늘 화면에서 기록을 확인할 수 있습니다.
