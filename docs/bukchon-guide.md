# 북촌 가이드

- 공개 경로: `/guide`. 공통 상단 메뉴와 홈페이지 하단 안내에서 연결한다.
- 맛집 7곳: 사용자가 제공한 Restaurant Recommendations 노션 문서에서 이름, 음식 소개, 지도 링크를 옮겼다. 별점·수상 경력·영업시간·가격은 확인 없이 추가하지 않는다.
- 투어: 기존 `/tours` 예약 목록과 서울도보해설관광 공식 사이트로 연결한다.
- 여행지: 서울한옥포털과 Visit Seoul의 전통문화 코스 안내를 바탕으로 북촌, 궁궐, 인사동을 소개한다. 원문 링크는 화면에 제공한다.
- 콘텐츠 편집: `lib/bukchon-guide.ts`의 `guideEntries`에 한국어/영어 이름·설명·분류·링크를 함께 등록한다. 노션과 자동 동기화하지 않는다.
- 한국어/영어 전환, 전체/맛집/투어/여행지 필터, 이름·음식 검색을 제공한다.
- 새로운 DB 테이블이나 마이그레이션은 필요하지 않다.

## 고객 문의 알림 회원 선택

수신자 설정의 GET 응답에는 해당 숙소를 관리할 수 있는 활성 회원(`members`)이 포함된다. 관리자는 전체 숙소, 매니저는 배정 숙소에 대해 선택할 수 있다. 전화번호가 없는 회원도 선택할 수 있으며 연락처 등록 안내를 표시한다. 저장 시에는 서버가 최신 회원 정보를 조회하여 유효한 전화번호가 있는지 검증한다. 회원 목록 새로 불러오기는 저장하지 않은 선택을 유지한다.

PUT은 `{ enabled, recipients: [{ userId }] }`만 받는다. 서버가 회원 정보에서 이름과 휴대폰 번호를 가져와 기존 JSON 수신자 목록에 `userId`와 함께 저장한다. 임의 전화번호 제출, 중복 번호, 부적격 회원을 거부한다. 발송 대상 결정 시 회원 연락처와 권한을 다시 조회한다.

기존에 직접 입력해 저장한 수신자는 다음 설정 저장 전까지 유지한다. 화면에서 다시 저장할 때는 등록 회원을 선택해야 한다. 이전에 생성된 알림의 번호가 변경되면 해당 이전 번호로의 발송은 취소된다.
