# Hosting Manager design context

This records the user's existing direction from the project conversation. It is not a new visual redesign or evidence that the requested features are already implemented.

## Operations screens

- The main users are the super manager, business administrators, managers, and cleaning staff. Make the current business/property scope and available actions clear.
- The user prefers the clarity of Clobe's management interface. Prioritize practical operational information, understandable menus, and fast access to today's work and the calendar.
- Keep existing approved components, colors, typography, and spacing as the starting point. Inspect current code for actual tokens; no replacement palette or font has been authorized by this setup.
- Show useful actions and status information without adding decorative summary cards. The user has repeatedly asked to remove unnecessary cards that increase clutter and loading time.
- On narrow mobile screens, retain calendar bars representing the stay period. Improve readability and placement without hiding the information needed to understand bookings and cleaning assignments across month boundaries.
- Give immediate navigation/loading feedback and clear empty, failure, and retry states. Preserve entered data where possible.
- Make routine cleaning, laundry, inventory, and report entry short and practical. Respect the user's established text-based supply requests and simplified laundry input.

## Guest and brand screens

- Public booking, guides, tours, invitation, and guest-stay screens have their own approved visual context; do not apply an operations dashboard layout indiscriminately.
- Preserve the voidanchae mark, the emphasized Korean name `안채,`, approved photography, and existing invitation interactions when working in their respective contexts.
- Use real project assets and confirmed operational content. Do not invent guest names, reviews, statistics, property policies, or service availability.

## Applying changes

Use the current screen and the latest explicit user request as the detailed brief. Preserve working booking, messaging, permission, and operational behavior while improving presentation. Check relevant desktop and mobile views, visible interaction states, and reduced-motion behavior when animation changes.
