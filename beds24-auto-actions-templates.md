## Beds24 Auto Action Setup Guide

For each message above, create an Auto Action in Beds24:

1. Go to **Settings → Guest Management → Auto Actions**
2. Click **Add Auto Action**
3. Configure:
   - **Name:** `[Property] - [Message Type]` (e.g., "Unwadang - Booking Confirmation")
   - **Property:** Select the corresponding property
   - **Action Type:** Send Message
   - **Trigger:** 
     - Booking Confirmation → "New booking" 
     - Check-in Day 9AM → "Days before check-in = 0" + Time 09:00
     - Check-in Day Noon → "Days before check-in = 0" + Time 12:00
     - Day After Check-in → "Days after check-in = 1" + Time 10:00
     - Checkout Day → "Days before checkout = 0" + Time 08:00
   - **Channel:** OTA message (for OTA bookings) / Email (for direct bookings)
   - **Message:** Copy the template text from above

4. **Test:** Create a test booking to verify messages are triggered correctly
